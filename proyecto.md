Sí. Esta idea puede quedar muy bien para Ingeniería Industrial, especialmente porque la puedes enfocar en logística, almacenes, inventarios y reducción de tiempos.

  

Podrías llamarla “Almacén Fácil” o “SmartWarehouse”.

  

📱 ¿Cómo funcionaría?

  

La idea principal es que una persona pueda buscar un producto en la app y que esta le diga exactamente dónde encontrarlo dentro del almacén.

  

Por ejemplo:

  

🔎 Buscas: Tornillos 1/4”

  

La app te muestra:

  

📦 Tornillos 1/4”

  

\* Cantidad disponible: 350 piezas

\* Pasillo: 3

\* Estante: B

\* Nivel: 2

\* Ubicación: P3-B-02

  

Así el trabajador no tiene que recorrer todo el almacén buscando.

  

⸻

  

1\. 📦 Registrar los productos

  

Primero se registra cada producto:

  

Producto Código Cantidad Pasillo Estante Nivel

Tornillos 1/4” T001 350 3 B 2

Tuercas 1/4” T002 520 3 B 3

Guantes G001 80 1 A 1

Cinta industrial C001 45 2 C 2

  

Incluso podrías agregar una foto del producto para identificarlo más fácilmente.

  

⸻

  

2\. 🔎 Buscar un producto

  

El trabajador abre la app y escribe:

  

“Guantes”

  

La app muestra:

  

🧤 Guantes de seguridad

📍 Pasillo 1

🗄️ Estante A

↕️ Nivel 1

📦 Existencia: 80 piezas

  

Podría tener un botón:

  

➡️ “Ver ubicación”

  

Y mostrar un pequeño mapa del almacén.

  

⸻

  

3\. 🗺️ Mapa del almacén

  

Esta sería una función que podría hacer que tu proyecto destaque.

  

Por ejemplo:

  

ALMACÉN

PASILLO 1 PASILLO 2 PASILLO 3

┌───────┐ ┌───────┐ ┌───────┐

│ A │ │ A │ │ A │

│ │ │ │ │ │

├───────┤ ├───────┤ ├───────┤

│ B │ │ B │ │ B ← │

│ │ │ │ │ Torn. │

└───────┘ └───────┘ └───────┘

  

La aplicación podría marcar dónde está el producto.

  

⸻

  

4\. 📲 Código QR

  

Otra función interesante sería poner un QR en cada estante.

  

El trabajador llega al estante, escanea:

  

QR → Estante B2

  

Y la app muestra todos los productos que deberían estar ahí.

  

Por ejemplo:

  

📍 Ubicación B2

  

• Tornillos 1/4” — 350 piezas

• Tornillos 3/8” — 210 piezas

• Arandelas — 500 piezas

  

Esto también ayudaría a detectar si un producto está colocado en el lugar equivocado.

  

⸻

  

5\. 📉 Control de inventario

  

La app también podría actualizar las cantidades.

  

Si había:

  

350 tornillos

  

y se retiran:

  

50

  

la aplicación queda en:

  

300 piezas disponibles.

  

Podría mostrar una alerta:

  

⚠️ Stock bajo

Tornillos 1/4”: 25 piezas

Stock mínimo: 50

  

⸻

  

6\. 📊 Indicadores

  

Aquí entra fuerte la parte de Ingeniería Industrial.

  

La app podría medir:

  

\* ⏱️ Tiempo promedio para encontrar un producto.

\* 📦 Productos encontrados correctamente.

\* 🔎 Número de búsquedas.

\* ⚠️ Productos mal ubicados.

\* 📉 Productos con stock bajo.

\* 🚶 Distancia recorrida para localizar productos.

\* 📊 Rotación de inventario.

  

Por ejemplo, podrías comparar:

  

Antes de la aplicación:

⏱️ 8 minutos para encontrar un producto.

  

Después:

⏱️ 2 minutos.

  

➡️ Reducción del tiempo de búsqueda: 75%.

  

Eso te daría un resultado muy bueno para presentar.

  

⸻

  

🏭 ¿Y cómo sería tu proyecto?

  

Podrías plantearlo como:

  

“Diseño de una aplicación móvil para optimizar la localización y control de productos dentro de un almacén.”

  

Problema

  

Los trabajadores pierden tiempo buscando productos porque no existe un sistema organizado de ubicación.

  

Solución

  

Crear una aplicación que permita:

  

Registrar → Ubicar → Buscar → Encontrar → Actualizar inventario → Analizar

  

🎯 Objetivo

  

Reducir los tiempos de búsqueda y mejorar el control de inventarios mediante una herramienta digital de localización de productos.

  

⸻

  

⭐ Y lo mejor: no necesitas una empresa real

  

Puedes crear un almacén ficticio para el proyecto.

  

Por ejemplo:

  

Almacén Industrial “XYZ”

  

Con:

  

\* 5 pasillos

\* 10 estantes por pasillo

\* 50 productos

\* Códigos QR

\* Inventario inicial

\* Ubicaciones

\* Datos de prueba

  

Y puedes hacer una demostración:

  

“Vamos a buscar el producto X.”

  

La app dice Pasillo 3 → Estante B → Nivel 2.

  

Después puedes mostrar cuánto tiempo tardaría una persona con y sin la aplicación.

  

Esta idea, en mi opinión, es incluso más adecuada para un proyecto de Ingeniería Industrial que la app de desperdicios, porque puedes relacionarla directamente con almacenes, logística, inventarios, tiempos, productividad y mejora de procesos.
